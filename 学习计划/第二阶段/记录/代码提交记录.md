```
CreateIdpAbstractPlatform()
  → CMsgpack2RosImagePlugin3::ioctl(IOCTL_MSGPACK2ROS_PUBLISH)
    → JpegPassthroughInterface::Invoke(topic, type, content)
      → MsgImageDataListJpegPassthrough()
         MSG_UNPACK → MsgImageDataList
         ├─ imageType==50 (JPEG) → rawData 直通（零解码零编码）
         │     → sensor_msgs::CompressedImage(format=jpeg)
         │     → publish(topic_name/索引/compressed)
         ├─ imageType==53 (H265) → H265Libde265Decoder::DecodeFrame() → I420
         │     → TurboJpegEncoder::EncodeI420() → JPEG
         │     → sensor_msgs::CompressedImage(format=jpeg)
         │     → publish(topic_name/索引/compressed)
         └─ 其它类型 → logged_types 记录一次后跳过（防刷屏）
```
