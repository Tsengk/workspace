# 自动驾驶传感器整体标定方案说明

> 本文档基于 `readme.txt` 的标定需求，结合当前工程中已实现的各功能模块，说明整体标定流程、各阶段算法原理与软件架构。

---

## 1. 系统概述

### 1.1 标定目标

| 传感器 | 标定参数 | 精度要求 |
|--------|----------|----------|
| 激光雷达 | x / y / z / roll / pitch / yaw | yaw < 0.3°，roll/pitch < 0.5° |
| 相机 | x / y / z / roll / pitch / yaw | yaw < 0.3°，roll/pitch < 0.5° |
| 毫米波雷达 | x / y / z / roll / pitch / yaw | yaw < 0.5° |

在此之上还需完成：
- BEV 环视精标与拼接参数
- 前视三路相机（左前 + 前 + 右前）像素拼接参数

**前提条件**：定位（GNSS）已标定完毕，定位输出格式为 `nav_msgs/Odometry`（ENU 坐标系，正北=0，北偏东为正）。

### 1.2 坐标系约定

- **VCS（车辆坐标系）**：FLU，X=前，Y=左，Z=上；原点为后轴中心，z_offset（后悬离地高度，默认 0.37 m）
- **地面 VCS z 坐标**：≈ −z_offset（约 −0.37 m）
- **ENU**：东北天，用于 GNSS 联合标定中的全局投影

### 1.3 已实现模块总览

| 模块 | 包名 | 功能 | 状态 |
|------|------|------|------|
| LiDAR Roll/Pitch/Z 标定 | `lidar_rp_cali` | 地面平面拟合 | 已实现 |
| LiDAR 静态 Yaw 标定 | `lidar_yaw1` | 锥桶 PCA 直线拟合 | 已实现 |
| LiDAR+GNSS 联合 Yaw 标定 | `lidar_gnss_yaw` | 多帧全局投影一致性 | 已实现 |
| 双激光雷达联合标定 | `lidar_lidar_cali` | 锥桶 2D ICP | 已实现 |
| 相机-LiDAR 联合标定 | `image_lidar_calibration` | FASTLIVO2 标定板 PnP+BA | 方案已设计 |

## 2. 标定前期准备

### 2.1 场地要求

| 标定项 | 场地要求 |
|--------|----------|
| LiDAR Roll/Pitch | 前后 20~30 m、左右 5 m 平地，平地占比 ≥ 80% |
| LiDAR 静态 Yaw | 正前方 5~30 m 放置 6 个锥形桶，周边 1 m 无杂物 |
| LiDAR+GNSS 联合 Yaw | 正前方 5~40 m 放置 6 个锥形桶且排成一条直线 |
| 双 LiDAR 联合 | 共视区域 5~40 m 内随机移动 FASTLIVO2 标定板 |
| 相机-LiDAR 联合 | 共视区域 5~15 m（最佳 8~12 m）随机移动 FASTLIVO2 标定板 |
| 环视标定 | 车辆四周约 3 m 处铺 3×3 棋盘格标定布，地面平整 |
| 前视拼接 | 拼接处 5~10 m 放置 FASTLIVO2 标定板 |

### 2.2 辅助设备清单

- 锥形桶 × 6（高度约 0.75 m）
- FASTLIVO2 标定板 × 1（96 cm × 72 cm，8×6 内角点 + 4 圆孔 + 4 ArUco 标记）
- 3×3 棋盘格标定布（用于环视标定）

## 3. 驱动层设计

### 3.1 激光雷达驱动

驱动读取全局 `rosparam`，实时将原始点云坐标变换到 VCS：

| 参数名 | 说明 |
|--------|------|
| `{lidar_name}_cali_x` | X 方向修正量 (m) |
| `{lidar_name}_cali_y` | Y 方向修正量 (m) |
| `{lidar_name}_cali_z` | Z 方向修正量 (m) |
| `{lidar_name}_cali_roll` | Roll 修正量 (deg) |
| `{lidar_name}_cali_pitch` | Pitch 修正量 (deg) |
| `{lidar_name}_cali_yaw` | Yaw 修正量 (deg) |

变换公式：`p_vcs = R(roll, pitch, yaw) · p_lidar + t`

### 3.2 毫米波雷达驱动

同激光雷达，使用 `{radar_name}_cali_*` 系列参数，点云以 `PointCloud2` 格式发布。

### 3.3 相机驱动

按配置发布对应 `rostopic`，支持内参矫正（undistort）图像的可选输出。

## 4. 标定流程详述

### 4.1 阶段一：LiDAR Roll / Pitch / Z 标定

**包**：`lidar_rp_cali`
**车辆状态**：静止
**标定参数**：roll、pitch、z（垂直安装高度）

#### 算法原理

```
原始点云（LiDAR 帧）→ 驱动变换（用安装参数）→ VCS 点云
                                ↓
                    地面检测（高度过滤 + 体素降采样 + 统计滤波 + 欧氏聚类）
                                ↓
                    平面拟合（RANSAC / 最小二乘 / PCA）
                                ↓
                    提取法向量 n = (nx, ny, nz)
                                ↓
              roll_err  = atan2(ny, nz)
              pitch_err = atan2(-nx, nz)
              z_err     = 平面截距 + z_offset（期望地面 z = -z_offset）
                                ↓
                    滑动窗口取加权均值 → 输出修正量
```

#### 关键参数（`lidar_rp_cali/config/params.yaml`）

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `ground.min/max_distance` | 2 / 30 m | 地面点水平距离范围 |
| `ground.voxel_size` | 0.2 m | 体素降采样分辨率 |
| `plane.method` | RANSAC | 可选 RANSAC / LEAST_SQUARES / PCA |
| `plane.ransac_distance_threshold` | 0.05 m | 内点阈值 |
| `cali.window_size` | 10 帧 | 滑动窗口大小 |

#### 精度指标

- Roll / Pitch < 0.5°
- Z 误差 < 0.02 m

---

### 4.2 阶段二：LiDAR 静态 Yaw 标定

**包**：`lidar_yaw1`
**车辆状态**：静止
**前提**：Roll / Pitch / Z 已标定
**标定参数**：yaw

#### 算法原理

```
VCS 点云（Roll/Pitch/Z 已修正）
        ↓
高度过滤：选取 z ∈ [地面+0.08, 地面+0.80] 的点（锥桶高度范围）
        ↓
体素降采样 + 欧氏聚类
        ↓
过滤：圆形半径 < 0.5 m，点数 5~500 → 锥桶中心列表
        ↓
PCA 拟合锥桶中心连线 → 直线主方向角 θ（相对 VCS X 轴）
        ↓
delta_yaw = -θ
yaw_calib = yaw_install - θ
R_calib   = Rz(delta_yaw) · R_install（四元数合成）
```

**物理含义**：若锥桶摆放在车辆正前方成一列，其在 VCS XY 平面的最优直线方向应与 X 轴（正前方）平行；偏角 θ 即为 Yaw 安装误差。

#### 精度指标

- Yaw < 0.2°（典型情况）

---

### 4.3 阶段三：LiDAR + GNSS 联合 Yaw 标定

**包**：`lidar_gnss_yaw`
**车辆状态**：小范围运动（5~10 km/h，多角度靠近锥桶）
**前提**：Roll / Pitch / Z 已标定，GNSS 已标定
**标定参数**：yaw（精度更高，利用多帧运动观测）

#### 算法原理

全局投影一致性最小化：

```
每一帧 i：
  q_j   = LiDAR 检测到的锥桶中心（LiDAR 帧）
  [xg,yg,ψ] = GNSS 输出（后轴中心全局位置，ψ=heading）

  p_global = R_bg(ψ) · (R_lb(δ) · q_j + t_lb) + [xg, yg]
  其中：
    R_bg(ψ) = [[sin(ψ), -cos(ψ)], [cos(ψ), sin(ψ)]]  （导航航向→ENU）
    R_lb(δ) = Rz(yaw_install + δ)（带待标定 Yaw 误差 δ）

优化目标：min_δ ∑_j ||p_global_j - 直线拟合残差||²

两阶段搜索：
  ① 粗搜：步长 0.05°，范围 ±5°
  ② 精搜：黄金分割法，精度 0.001°
```

#### 精度指标

- Yaw < 0.2°（多帧融合，优于静态方法）

---

### 4.4 阶段四：双激光雷达联合标定

**包**：`lidar_lidar_cali`
**车辆状态**：静止
**前提**：主雷达完全标定；辅雷达 Roll / Pitch / Z 已标定
**标定参数**：辅雷达 x、y、yaw（相对 VCS 的修正量）

#### 算法原理

```
主雷达点云（VCS，完全标定）  →  锥桶检测  →  主雷达锥桶中心集合 P_master
辅雷达点云（VCS，近似值）    →  锥桶检测  →  辅雷达锥桶中心集合 P_sub
                                    ↓
             粗搜索：以 (Δx=0, Δy=0, Δyaw=0) 为中心，网格搜索
               范围：±2 m（x/y），±30°（yaw），步长 0.1 m / 2°
                                    ↓
             精搜索：2D ICP（SVD）迭代求 ΔT = (Rz(Δyaw), [Δx, Δy])
                                    ↓
             修正公式：
               yaw_calib = yaw_install + Δyaw
               x_calib   = cos(Δyaw)·x_install − sin(Δyaw)·y_install + Δx
               y_calib   = sin(Δyaw)·x_install + cos(Δyaw)·y_install + Δy
```

**帧累积**：静止场景多帧（默认 10 帧）锥桶融合，提升稳定性。

#### 验证指标

- 双雷达静态重合度 < 5 cm

---

### 4.5 阶段五：相机 + LiDAR 联合标定

**包**：`image_lidar_calibration`（方案已设计，待完整实现）
**车辆状态**：静止，随机移动 FASTLIVO2 标定板（5~15 m，建议 8~12 m）
**前提**：LiDAR 完全标定（点云已在 VCS 下），相机内参已标定
**标定参数**：相机外参 x / y / z / roll / pitch / yaw

#### 算法原理

利用 FASTLIVO2 标定板（4 圆孔 + 4 ArUco + 棋盘格）建立 3D-2D 对应关系：

```
图像端：
  亚像素棋盘格角点检测（精度 ±0.1 px）
  + 圆孔中心检测（精度 ±0.05 px）
  → 图像点集 {u_i}

LiDAR 端（VCS 下）：
  RANSAC 平面分割 → 标定板所在平面
  + 圆孔边缘点检测（穿孔检测地面约束）
  → 3D 点集 {P_i}

求解：
  ① EPnP 初始解
  ② Levenberg-Marquardt 迭代优化
  ③ 多约束光束法平差（重投影误差 + 孔洞约束 + 地面约束）
  → T_camera_to_vcs = (R, t)
```

#### 精度指标

| 指标 | 要求 | FASTLIVO2 预期 |
|------|------|----------------|
| 平均重投影误差 | < 1.0 px | 0.3~0.8 px |
| 最大重投影误差 | < 3.0 px | 1.0~2.0 px |
| 角度标定精度 | < 0.2° | 0.05~0.12° |
| 成功率 | > 90% | > 95% |

#### 验证

激光点云投影到图像误差 < 2 像素。

---

### 4.6 阶段六：相机间联合标定

**车辆状态**：静止，随机移动 FASTLIVO2 标定板
**前提**：参考相机已完成 LiDAR 联合标定，内参已标定
**标定参数**：待标定相机外参（全部 6 自由度）

#### 算法原理

```
参考相机已知外参 T_ref，待标定相机外参 T_target（待求）
标定板在参考相机坐标系下的位置 P_ref = T_ref · P_3d

最小化：||π(K_target, T_target, P_3d) - p_target_detected||²
（p_target_detected = 待标定相机检测到的标定板角点）

多位置采集（≥5 组）+ 光束法平差
```

**界面**：2D 界面以不同深浅显示两台相机的投影重叠情况；SpinBox 实时调整 6 个外参并预览效果。

---

### 4.7 阶段七：BEV 环视精标

**车辆状态**：静止
**前提**：前后左右 4 台相机外参已由阶段五/六完成初始标定
**标定布**：车辆四周约 3 m 处铺 3×3 棋盘格标定布

#### 算法原理

```
各相机：去畸变 → 透视变换（H）→ 鸟瞰图（BEV）
棋盘格检测 → 2D-2D 单应矩阵 H_i 精细化优化
拼接误差最小化：相邻相机重叠区域像素对齐
```

**输出参数**：每台相机的 BEV 单应矩阵 H（3×3），写入 `bev_calibration.yaml`。

#### 验证指标

- 拼接误差 < 2 cm（地面实际距离）

---

### 4.8 阶段八：前视三路拼接标定

**车辆状态**：静止
**相机**：左前 + 前 + 右前（共 3 路）
**目标**：将左前、右前像素投影到前视相机扩展画布

#### 算法原理

```
前视相机（原图，不做内参矫正）：1280×720 → 中央 1280×720
左前相机投影参数 H_left：像素 → 前视相机左扩展区 640×720
右前相机投影参数 H_right：像素 → 前视相机右扩展区 640×720
拼接结果：2560×720（左640 + 中1280 + 右640）

优化：FASTLIVO2 标定板在拼接处的像素对准误差最小化
```

**地面刻度**：以车头为零点，在前视图像上叠加 20 m 地面刻度线（每 5 m 一格），用于直观验证。

#### 可调参数

- 左前/右前相机上下平移量与裁剪范围（SpinBox 实时生效）

## 6. 标定执行顺序

```
① LiDAR Roll/Pitch/Z 标定（lidar_rp_cali）
         ↓
② LiDAR 静态 Yaw 标定（lidar_yaw1）
   或
② LiDAR+GNSS 联合 Yaw 标定（lidar_gnss_yaw，精度更高）
         ↓
③ 双激光雷达联合标定（lidar_lidar_cali，如有多雷达）
         ↓
④ 相机-LiDAR 联合标定（image_lidar_calibration）
         ↓
⑤ 相机间联合标定（多相机系统）
         ↓
⑥ 毫米波雷达标定（参照相机-LiDAR 流程，以已标定 LiDAR 为参考）
         ↓
⑦ BEV 环视精标
         ↓
⑧ 前视三路拼接标定
```

> 每完成一步后，`save_calibration` 将结果写入 `cali_result/` 并更新 `rosparam`，下游步骤可直接使用。
