# 第二阶段输出物汇总模板（第5-8周）

> 配套主文件：`应用型软件工程师培养清单-农式曾.md`
>
> 使用方式：每完成一个输出物，更新其状态并补充链接/路径，第8周验收时整体核查。
>
> 本阶段目标：完成一个真实工具类小功能的全流程闭环（任务确认 → 功能拆解 → 开发 → 自测 → 联调优化 → 使用说明 → 复盘验收）。
