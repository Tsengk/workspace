# LiDAR Roll/Pitch 标定系统 — 测试报告

**项目**: `lidar_rp_cali`
**日期**: 2026-03-23
**平台**: ROS1 Noetic | Ubuntu 20.04
**坐标系**: FLU（前左上，X=前，Y=左，Z=上）
**仿真雷达**: 速腾 Robosense RS-Ruby 80 线

---

## 1. 系统概述

本系统实现了基于地面平面拟合的激光雷达 Roll（横滚角）和 Pitch（俯仰角）自动标定。
通过仿真速腾 RS-Ruby 80 线雷达生成真实感点云，依次对 8 种场景进行标定精度与鲁棒性验证。

### 1.1 处理流水线

```
LiDAR 点云（LiDAR 帧，FLU）
        │
        ▼
┌─────────────────────┐
│   GroundDetector    │  高度过滤 → 距离过滤 → 体素降采样
│   地面点检测         │  → 统计离群点去除 → 欧几里得聚类
└──────────┬──────────┘
           │ 地面点云
           ▼
┌─────────────────────┐
│    PlaneFitter      │  RANSAC / 最小二乘 / PCA
│    平面拟合          │  → 平面模型 (ax+by+cz+d=0)
└──────────┬──────────┘
           │ 法向量 n = (n_x, n_y, n_z)
           ▼
┌─────────────────────┐
│ CalibrationCalc     │  Roll  = atan2(n_y, n_z)
│ 标定计算             │  Pitch = -atan2(n_x, √(n_y²+n_z²))
│                     │  → 滑动窗口置信度加权均值
└──────────┬──────────┘
           │ (Roll°, Pitch°, 置信度, 四元数)
           ▼
     TF 广播 / 话题发布
```

### 1.2 核心数学原理

**坐标系约定（FLU）**：LiDAR 安装误差旋转矩阵为

```
R_l2v = Ry(pitch_err) × Rx(roll_err)
```

**地面法向量在 LiDAR 帧**（从车辆帧变换到 LiDAR 帧）：

```
n_lidar = R_l2v^T × [0, 0, 1]^T
        = [ -sin(pitch),
             sin(roll)·cos(pitch),
             cos(roll)·cos(pitch) ]
```

**欧拉角反解**：

| 角度 | 公式 |
|------|------|
| Roll  | `atan2(n_y, n_z)` |
| Pitch | `-atan2(n_x, √(n_y² + n_z²))` |

## 2. 仿真器设计

### 2.1 RS-Ruby 80 线垂直角度分布

| 层段 | 角度范围 | 线束数 | 间距 |
|------|---------|--------|------|
| 低层  | −25° ~ −16° | 10 根 | 1.00° |
| 次低层 | −15.5° ~ −8.0° | 15 根 | 0.50° |
| 近地平线（密集） | −7.5° ~ +2.5° | 30 根 | ~0.34° |
| 上层  | +2.7° ~ +9.7° | 15 根 | 0.50° |
| 顶层  | +10.0° ~ +15.0° | 10 根 | ~0.56° |
| **合计** | **−25° ~ +15°** | **80 根** | — |

### 2.2 水平扫描参数

| 参数 | 值 |
|------|----|
| 水平分辨率 | 0.2°（1800 线/圈）|
| 最大量程 | 100 m |
| 单帧点数 | 80 × 1800 = **144,000 点** |
| 测距噪声模型 | 高斯，σ 可配置（默认 0.02 m）|

### 2.3 射线投射方法

射线方向（LiDAR 帧，FLU）：
```
d_lidar = [cos(el)·cos(az),  cos(el)·sin(az),  sin(el)]
```

变换到世界帧后与地面（z=0 平面）求交：
```
t = -H / d_world_z          （H = LiDAR 离地高度）
P_world = [0,0,H] + t × d_world
P_lidar = R_l2w^T × (P_world - [0,0,H])
```

障碍物采用轴对齐包围盒（AABB）射线求交，先障碍后地面，取最近命中点。

## 6. 观察与分析

### 6.1 置信度规律

- **开阔地面**（场景 01、07）：置信度最高（~0.988），地面点云密集、平整
- **含障碍物**（场景 03、04）：置信度降至 0.500，但精度不受影响
  - 原因：障碍物减少了有效地面点数，RMS 误差和曲率指标变差，但 RANSAC 仍能正确拟合主平面
- **高噪声**（场景 06）：置信度 0.943，略低于理想场景但远高于阈值（0.2）

### 6.2 不同场景精度对比

城市峡谷（场景 04）出现的 Roll 0.002°、Pitch 0.001° 误差是所有场景中最大的，
原因是两侧建筑大幅减少了可见地面范围，地面点分布不均匀导致聚类中心偏移。
但此误差仍远低于 0.3° 容差要求。

### 6.3 坡道场景的正确性

场景 08 验证了坐标系设计的正确性：
- 车辆姿态随道路倾斜，车辆坐标系 z=0 始终对应路面
- 标定仅感知 LiDAR 相对车辆的安装误差（roll=1°, pitch=−0.5°）
- 路面坡度（5°）被车辆姿态吸收，不进入标定结果
