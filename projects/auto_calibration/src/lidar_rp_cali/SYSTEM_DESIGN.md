# LiDAR Roll and Pitch Calibration System - 方案说明文档

## 1. 项目概述

本项目实现了一个完整的ROS1 LiDAR横滚角(Roll)和俯仰角(Pitch)自动校准系统。该系统通过检测LiDAR点云中的地面点，拟合平面并计算最优的姿态校准参数，为自动驾驶和机器人导航提供精确的传感器标定。

### 1.1 系统目标
- 实现亚度级校准精度（误差<0.3°）
- 支持多种真实环境场景
- 提供实时校准能力（10Hz更新率）
- 具备鲁棒的离群点处理能力

### 2.2 核心组件

#### 2.2.1 GroundDetector (地面检测器)
**功能**: 从LiDAR点云中识别和提取地面点

**算法流程**:
1. **高度过滤**: 保留在`min_height` ~ `max_height`范围内的点
2. **距离过滤**: 保留在`min_distance` ~ `max_distance`范围内的点
3. **体素网格降采样**: 使用`voxel_size`进行降采样以提高性能
4. **统计离群点去除**: 基于均值和标准差过滤噪声点
5. **欧几里得聚类**: 提取最大的地面点簇

**关键参数**:
- `min_height`: -1.5m (地面最低点)
- `max_height`: 0.3m (地面最高点)
- `voxel_size`: 0.2m (降采样分辨率)
- `min_cluster_points`: 200 (最小聚类点数)

#### 2.2.2 PlaneFitter (平面拟合器)
**功能**: 使用多种算法拟合三维平面

**支持算法**:

1. **RANSAC (随机抽样一致性)**
   - 适用于存在离群点的情况
   - 鲁棒性强，能处理噪声数据
   - 参数: `distance_threshold`, `max_iterations`

2. **Least Squares (最小二乘法)**
   - 适用于干净数据
   - 计算精度高
   - 基于协方差矩阵特征分解

3. **PCA (主成分分析)**
   - 统计方法
   - 计算效率高
   - 利用PCL库实现

**输出参数**:
- `normal`: 平面法向量 (a, b, c, d)
- `curvature`: 平面曲率
- `inliers`: 内点数量
- `rms_error`: 均方根误差

#### 2.2.3 CalibrationCalculator (校准计算器)
**功能**: 从平面法向量计算Roll和Pitch角度

**坐标系定义**:
- **FLU标准**: Front+(X), Left+(Y), Up+(Z)
- 对于水平地面，法向量应为(0, 0, 1)

**计算原理**:
- **Roll**: `atan2(normal_y, normal_z)`
- **Pitch**: `-atan2(normal_x, sqrt(normal_y^2 + normal_z^2))`
- **Yaw**: 0 (地面校准不考虑偏航角)

**特性**:
- 欧拉角提取和验证
- 四元数生成用于TF广播
- 多角度平均提高精度
- 置信度评分系统

#### 2.2.4 Main ROS Node (主节点)
**功能**: 协调整个校准流程并提供ROS接口

**主要特性**:
- ROS参数服务器集成
- 实时点云处理流水线
- TF变换自动广播
- 服务接口用于触发校准
- 多话题输出用于监控

## 4. 算法详细设计

### 4.1 地面检测算法

```cpp
bool GroundDetector::detectGround(input_cloud, output_ground) {
  // 1. 高度过滤
  filterByHeight(input_cloud, temp_cloud);

  // 2. 距离过滤
  filterByDistance(temp_cloud, filtered_cloud);

  // 3. 体素网格降采样
  applyVoxelGrid(filtered_cloud, downsampled_cloud);

  // 4. 离群点去除
  removeOutliers(downsampled_cloud, clean_cloud);

  // 5. 聚类提取
  extractGroundClusters(clean_cloud, output_ground);
}
```

### 4.2 平面拟合算法对比

| 算法 | 优点 | 缺点 | 适用场景 |
|------|------|------|----------|
| RANSAC | 抗离群点强 | 计算量较大 | 城市环境 |
| Least Squares | 精度高 | 对噪声敏感 | 干净数据 |
| PCA | 效率高 | 需要足够点数 | 实时应用 |

### 4.3 校准计算流程

```cpp
CalibrationResult calculateCalibration(plane_normal) {
  // 1. 归一化法向量
  Eigen::Vector3f normal = normalize(plane_normal);

  // 2. 计算欧拉角
  double roll = atan2(normal[1], normal[2]);
  double pitch = -atan2(normal[0], sqrt(normal[1]^2 + normal[2]^2));

  // 3. 角度验证
  if (!validateAngles(roll, pitch)) return invalid_result;

  // 4. 生成四元数
  Eigen::Quaterniond quat = createQuaternion(roll, pitch);

  // 5. 计算置信度
  double confidence = calculateConfidence(plane_quality);

  return CalibrationResult(roll, pitch, quat, confidence);
}
```

## 5. 性能优化策略

### 5.1 实时性优化
- **体素降采样**: 减少点云数量，提高处理速度
- **并行处理**: 利用多线程处理不同阶段
- **内存池**: 预分配内存减少动态分配开销

### 5.2 精度优化
- **多角度平均**: 融合多次测量结果
- **自适应参数**: 根据环境复杂度调整参数

### 5.3 鲁棒性优化

- **异常检测**: 识别并处理异常测量
