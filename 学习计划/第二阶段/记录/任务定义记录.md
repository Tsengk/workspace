## 任务定义表

| 字段 | 内容 |
|------|------|
| **任务来源** | ap_tools 平台图像发布能力扩展需求（功能新增类）：在 `ap_interface_use/plugins/` 图像插件体系中新增第 3 个图像插件 `msgpack2ros4imageplugin3`，用于把 msgpack 压缩图像数据转换为 ROS `sensor_msgs::CompressedImage` 并发布。对应实现提交：`83b0f84e`（2026-08-06，「增加图像转换插件3用于转换JPEG格式」，作者 nongshizeng），为插件第一版。 |
| **任务目标** | 完成插件 `msgpack2ros4imageplugin3` 第一版开发，实现混合图像转换发布：<br>① JPEG（imageType=50）rawData 直接透传发布，零解码零编码；<br>② H265 裸流（imageType=53）经 libde265 软解码为 I420，再经 TurboJPEG 编码为 JPEG 发布；<br>③ 以 `sensor_msgs::CompressedImage` 在 `topic_name/索引/compressed` 话题发布；<br>④ 支持 Ubuntu 18.04 / 20.04 双平台编译（compile_1804.sh / compile_2004.sh），产物 `libmsgpack2rosimageplugin3.so` 部署至 `ap_tools_chain/runtime/x86_1804/bin`。 |
| **任务边界** | ① 只处理 imageType=50（JPEG 透传）与 53（H265 转 JPEG）；其余格式（H264=52、裸格式 0-19 等）仅记录一次并跳过，不做转换；<br>② 话题命名采用 plugin1 的索引形式（`topic_name/索引/compressed`），不采用 plugin2 的 frameID + `/image/compressed` 形式；<br>③ 第一版范围不含：bag 写入、输出话题编号调整、透传性能优化、H265 解码线程池并行；<br>④ 解码用 libde265 软解码、编码用 TurboJPEG，不做 NVENC 硬解码；<br>⑤ 每路 topic 独立 decoder/encoder 实例，解码线程数 decoder_threads_=2，JPEG 质量 jpeg_quality_=85；<br>⑥ 依赖 libde265、turbojpeg、ROS melodic/noetic、idpware 库，运行平台 Ubuntu 18.04/20.04。 |
| **截止时间** | 按培训计划第5周截止（第1-4周已于 2026-06-30 验收，第5周约 2026-06-30 ~ 07-06 结束）；实际第一版提交于 2026-08-06 完成，执行已顺延，具体日期以主管确认的周计划为准。 |
| **对应工具软件** | `ap_tools`（`/home/idriver/TOOLS/ap_tools`），具体模块：`ap_interface_use/plugins/msgpack2ros4imageplugin3/` |
| **涉及模块/页面** | `ap_interface_use/plugins/msgpack2ros4imageplugin3/`：<br>`cmsgpack2rosimageplugin3.cpp`（插件入口）、`function4pub/avos_rospublish_jpeg_interface.{h,cpp}`（转换发布核心）、`function4pub/h265_libde265_decoder.hpp`（libde265 解码封装）、`function4pub/turbojpeg_encoder.hpp`（TurboJPEG 编码封装）、`CMakeLists.txt`（构建）、`compile_1804.sh` / `compile_2004.sh`（编译脚本） |
| **相关接口/脚本** | 插件接口 `CIdpAbstractPlatform`（open/write/read/ioctl/close）+ 导出 `CreateIdpAbstractPlatform`/`DestroyIdpAbstractPlatform`；IOCTL：`IOCTL_INIT_PRARM`、`IOCTL_MSGPACK2ROS_PUBLISH`（`SPublishParam`：topic/type/content）；转换入口 `JpegPassthroughInterface::Invoke(topic, type, content)`，消息类型 `MsgImageDataList`（imageType=50/53）；发布话题 `sensor_msgs::CompressedImage`；编译脚本 `compile_1804.sh` / `compile_2004.sh` |
