# 雷达标定使用激光雷达融合参数修复说明

## 问题描述

毫米波雷达-激光雷达联合标定过程中，LiDAR driver 启动时使用的参数为 `aian_2936.yaml` 的裸安装值（`getLidarInstall()`），未经过 `process/` 目录中已标定结果的叠加合并。

导致操作员在雷达标定界面中看到的 LiDAR 点云位置与精标后的真实位置不一致，手动对齐保存的雷达绝对位姿存在系统性偏差。

## 根因

`src/calibration_gui/src/tab_radar_lidar.cpp` `onLidarSelected()` 中：

```cpp
// 修改前：使用裸安装值
cfg_->getLidarInstall(current_lidar_, x, y, z, roll, pitch, yaw);
```

而 `getLidarInstall()` 只读取 `aian_2936.yaml` 中的原始安装值，`process/` 目录下已完成的标定结果（`lidar_rp_` / `secondary_rp_` / `lidar_yaw_` / `lidar_lidar_`）完全没有被纳入。

## 修改方案

将 LiDAR 参数的获取方式从 `getLidarInstall()` 替换为 `getMergedLidarParams()`，后者会自动按优先级合并：

```
基础: aian_2936.yaml 安装值
覆盖: lidar_rp_ → secondary_rp_ → lidar_yaw_ → lidar_lidar_ (按序叠加)
```

## 改动内容

| 位置 | 修改前 | 修改后 |
|---|---|---|
| `tab_radar_lidar.cpp:332-338` 显示标签 | `getLidarInstall()` | `getMergedLidarParams()` |
| `tab_radar_lidar.cpp:350-358` driver 启动参数 | `getLidarInstall()` | `getMergedLidarParams()` |

## 安全性

`lidarIsCalibrated()` 前置校验已确保 `getMergedLidarParams()` 在到达 driver launch 代码时必然返回有效值（至少有一个 process 文件存在），不会出现传零值启动的情况。

## 效果

- LiDAR 点云显示在精标后的正确位置
- 操作员对齐雷达点云时参考的是准确的 LiDAR 参考系
- 保存的 `radar_lidar_<radar>.yaml:calibrated:` 为正确的雷达绝对位姿
