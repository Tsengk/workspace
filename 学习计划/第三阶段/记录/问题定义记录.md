## 问题定义表

| 字段 | 内容 |
|------|------|
| **问题来源** | auto_calibration 标定软件在「雷达-激光雷达联合标定」与「相机-LiDAR 可视化标定」过程中发现的两类问题，已定位并修复（提交 `84cbc0c4`），修复前以两份修复说明文档作为问题定义 |
| **问题现象** | **问题A（雷达标定）**：毫米波雷达-激光雷达联合标定时，LiDAR driver 使用 `aian_2936.yaml` 的裸安装值（`getLidarInstall()`），未叠加 `process/` 目录已标定结果 → 雷达标定界面中 LiDAR 点云位置与精标后真实位置不一致，手动对齐保存的雷达绝对位姿存在系统性偏差。<br>**问题B（画面卡顿）**：导入车辆配置文件后，在「相机-LiDAR 标定」Tab 选择 `front_middle_lidar` + `front_120` 时画面卡顿（叠加图像不更新）；选择 `front_60` 等其它相机流畅。 |
| **复现步骤** | 问题A：打开标定软件 → 加载 `aian_2936` 车辆配置 → 进入雷达标定界面 → 选择某 LiDAR → 观察点云位置与已标定结果不符；手动对齐并保存后，`radar_lidar_<radar>.yaml` 位姿存在系统性偏差。<br>问题B：启动软件并导入车辆配置文件 → 进入「相机-LiDAR 标定」Tab → 选择 `front_middle_lidar` + `front_120` → 开启可视化 → 叠加图像不更新；切换 `front_60` 等相机则流畅。 |
| **影响范围** | 问题A：影响雷达-激光雷达联合标定结果准确性（保存的雷达绝对位姿系统性偏差），进而影响雷达-LiDAR 融合标定。<br>问题B：影响 `front_120` 相机 + `front_middle_lidar` 组合的相机-LiDAR 标定操作（画面卡死无法观察投影贴合度）；其它相机组合不受影响。 |
| **责任边界** | 属于 auto_calibration 标定软件自身缺陷（非传感器硬件或数据问题），由标定软件研发（nongshizeng）定位并修复，不涉及其它工具软件/平台：<br>问题A：参数合并逻辑，责任在标定 GUI 模块 `tab_radar_lidar.cpp`（应叠加标定结果而非只用裸安装值）；<br>问题B：时间戳同步逻辑，责任在投影节点 `lidar_camera_projection_node.cpp`（同步容差导致整帧跳过）。<br>修复结果需向主管/部署方同步并回归验证。 |
| **对应工具软件** | `auto_calibration`（标定软件，`/home/idriver/TOOLS/auto_calibration`）<br>问题A：`src/calibration_gui/src/tab_radar_lidar.cpp`（雷达-LiDAR 标定 Tab）<br>问题B：`src/lidar_camera_projection/src/lidar_camera_projection_node.cpp`（相机-LiDAR 投影节点） |
| **相关模块/页面/脚本** | 问题A：`tab_radar_lidar.cpp onLidarSelected()`、`ConfigManager::getLidarInstall()` / `getMergedLidarParams()`、`aian_2936.yaml`、`process/` 标定结果（`lidar_rp_`/`secondary_rp_`/`lidar_yaw_`/`lidar_lidar_`）<br>问题B：`lidar_camera_projection_node.cpp onTimer()` / `onCompressedImage()`、`sync_tolerance_sec_`、`front_120`/`front_middle_lidar` bag 数据来源 |
| **优先级** | 问题A：高（标定结果准确性，系统性偏差）；问题B：中高（画面卡顿影响标定操作） |
